# 卓札

クトゥルフ神話TRPGの探索者シートを、公開URLから移し、編集鍵つきで保存・共有する個人制作Webアプリです。

- 公開URLから能力値、技能、持ち物を取り込み
- 能力レーダーとコンパクトな編集面
- 閲覧URLと編集鍵を分離
- 判定コマンド、ココフォリア用の駒JSON、バックアップJSONを出力
- 秘匿メモは端末だけに保存

## 開発

```powershell
npm install
npm run dev
npm run check
npm test
npm run build
```

本番は `https://takufuda.yhay81.com` です。
